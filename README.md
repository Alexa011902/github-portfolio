## Projects

This portfolio includes three academic and personal projects that demonstrate my technical development and practical experience.

### 1. StudyBuddy AI

An AI-powered study assistant built with Python and Streamlit using Google's Gemini API. It includes features to explain topics, create study guides, and generate quizzes to support learning.

**Technologies:** Python, Streamlit, Google Gemini API

### 2. Simple Cache Simulator

A C++ project that simulates different computer cache organizations, including direct-mapped, set-associative, and fully associative caches. It tracks memory accesses, hits, misses, and miss rates to compare cache performance.

**Technologies:** C++

### 3. Ocean Data Explorer

A Python data analysis and visualization project that explores ocean-related information using a simulated sample dataset. It uses data processing and visualizations to examine ocean temperature, sea-level measurements, and plastic waste.

**Technologies:** Python, pandas, matplotlib
