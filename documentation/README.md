# Portfolio Project Documentation

This folder contains supporting documentation for the three projects included in the COSC 4272 portfolio.

## Project documents

1. [StudyBuddy AI Documentation](StudyBuddy-AI-Documentation.md) — describes the AI-powered study assistant, its features, technologies, setup, and testing.
2. [Simple Cache Simulator Documentation](Simple-Cache-Simulator-Documentation.md) — describes the C++ cache simulator, supported cache organizations, LRU replacement, and the sample test results.
3. [Ocean Data Explorer Documentation](Ocean-Data-Explorer-Documentation.md) — describes the Python data-analysis project, its dataset, calculations, charts, and setup.

Each document is based on the corresponding project's README. Where the README does not provide a detail, this documentation avoids assuming how that part was implemented.
