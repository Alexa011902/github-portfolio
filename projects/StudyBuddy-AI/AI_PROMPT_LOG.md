# AI Prompt Log – StudyBuddy AI

## Project Overview

This document records examples of AI prompts and assistance used during the development of StudyBuddy AI for the COSC 4272 Senior Seminar project.

**Note:** The prompts documented below are representative summaries of the AI assistance used throughout development. They are not verbatim transcripts of every interaction.

## AI Tools Used

- **ChatGPT:** Assisted with planning, code development, troubleshooting, and documentation.
- **Google Gemini API:** Used within the application to generate student-friendly explanations, study guides, and quizzes.

## Development Prompts and Assistance

### 1. Project Planning

**Prompt:** Help me plan and develop a simple AI-powered study assistant using Python.

**Purpose:** To identify the main features and technologies needed for the application.

### 2. Application Development

**Prompt:** Help me create a Streamlit application that allows students to explain topics, create study guides, and generate quizzes using the Gemini API.

**Purpose:** To develop the application's interface and connect it to the AI model.

### 3. API Configuration

**Prompt:** Help me configure the Gemini API key securely using a `.env` file.

**Purpose:** To keep the API key separate from the main application code.

### 4. Troubleshooting

**Prompt:** Help me troubleshoot issues with the application when it takes too long to generate an AI response or returns an API error.

**Purpose:** To identify potential problems and test solutions.

### 5. Documentation

**Prompt:** Help me document the application, its features, technologies, installation instructions, and development process.

**Purpose:** To prepare project documentation and instructions for future users.
