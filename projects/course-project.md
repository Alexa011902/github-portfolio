# Simple Cache Simulator

## Project Description

The Simple Cache Simulator is a C++ project that demonstrates how cache memory works. It simulates different cache mapping techniques and shows how memory references are handled by the cache.

The project helped me understand cache organization, cache hits and misses, and how replacement policies affect cache performance.

## Technologies Used

- C++
- Cache memory concepts
- Least Recently Used (LRU) replacement policy

## Main Features

- Direct-mapped cache
- 2-way set-associative cache
- 4-way set-associative cache
- Fully associative cache
- Cache hit and miss tracking
- LRU replacement policy
- Cache contents displayed after each memory reference
- Final miss-rate calculation
